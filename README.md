# Handwritten Character Recognition using CNN

## Overview

This project uses Deep Learning and Convolutional Neural Networks (CNN) to recognize handwritten digits from image data. The model is trained using the MNIST dataset, which contains thousands of handwritten digit images from 0 to 9.

The system learns image patterns and predicts handwritten digits with high accuracy.

## Features

* Handwritten digit recognition
* Image preprocessing and normalization
* Convolutional Neural Network (CNN) implementation
* Prediction visualization
* High accuracy digit classification

## Technologies Used

* Python
* TensorFlow
* Keras
* NumPy
* Matplotlib

## Dataset

MNIST Handwritten Digit Dataset

## Workflow

1. Import dataset
2. Normalize image data
3. Build CNN architecture
4. Train neural network
5. Evaluate model accuracy
6. Predict handwritten digits

## Model Accuracy

Achieved approximately 98% test accuracy.

## Applications

* OCR systems
* Bank cheque scanners
* Postal code recognition
* Exam paper digitization
* Handwriting recognition systems
